  extension reloads. Antigravity direct CLI sessions preserve Cox's live permission

  current thread titles.

  conflicts; generated worktree paths include repository identity; cleanup skips
  not-yet-due scans without weakening deletion safeguards. Hidden/minimized
  GitHub comments and reviews are filtered while hidden-count pagination stays
  correct.

  deletion fallback excluding side chats/subagents, preview-aware navigation,
  IME guards, Unicode-safe text bounds, reasoning batching, settings draft
  retention, narrower chat Git-status subscriptions and small editor/terminal/
  document-preview fixes.

  Calendar descriptions. One-click database reclaim was withdrawn after review
  found unsafe restart and shutdown deadlines; the existing offline doctor
  command and automatic incremental vacuum remain unchanged.
  Remote desktop profiles now require HTTPS and password authentication at both
  normalization and preflight.

  KaTeX 0.18.10 and undici 8.12.4.
