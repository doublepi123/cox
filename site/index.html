Cox Desktop

不开终端，也有你的​本地驾驶舱

macOS 与 Windows 桌面客户端内置 Web 界面和独立 Node 运行时，本地后端只监听回环地址。组合安装包自带 Cox 后端；仅客户端安装包首次本地会话需联网安装最新稳定版 Cox。

下载桌面版 macOS Apple Silicon / Intel · Windows x64

智能体 CLI、账号认证和模型订阅仍需单独配置。发布签名与平台验收说明见 Release。

在 Android 上使用 CoCode

CoCode 在 Android 手机上本地运行 Cox 和编码智能体，无需电脑，也不需要 root。

组合包或仅客户端，按需选择

两种安装包都不需要全局安装 Node 或 Cox。桌面数据保存在 ~/.cox/desktop，与 CLI 数据分开。

分阶段更新，失败可回滚

更新下载并校验后，在下次正常启动时激活。激活前备份数据，失败时恢复旧后端及对应的数据快照。

通过 HTTPS 连接远程服务器

连接你自己运营的 Cox 服务器需要 HTTPS 与密码。每个服务器使用独立的浏览器配置，远程页面无法管理本地后端或桌面更新。

本地控制面，不是云端托管

Cox 服务运行在你的电脑上，默认只监听 127.0.0.1。项目、对话、凭据与检查点留在本地数据目录，上游密钥由本地网关保管。

本地优先不等于离线推理：智能体仍会调用你配置的模型服务，Git 集成也可能访问相应的代码托管平台。

一条命令，开始构建

无需克隆仓库，也不用安装开发依赖。npm 包已包含构建好的界面与本地服务。

  1. 1

    运行 Cox

    在终端运行启动命令。如果浏览器没有自动打开，按终端提示访问本地地址。

  2. 2

    连接智能体

    在设置中添加智能体。CLI 型智能体需在本机安装并完成登录；也可以绑定模型服务。

  3. 3

    打开项目，开始构建

    添加本地项目目录，新建对话并选择模型，然后说出你的第一个想法。

Cox 不包含模型订阅或 API 额度，请使用你自己的账号与凭据。如果原生依赖没有适用于你平台的预编译版本，安装时可能需要 C/C++ 构建工具。
